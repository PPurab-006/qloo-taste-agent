# Qloo Agentic Hackathon: Requirements & Design Notes

## 1. Competition Overview

- **Competition:** [Qloo Agentic Hackathon](https://qloo.devpost.com/)
- **Core Mission:** Build an AI-powered agentic system or application where Qloo's cultural intelligence API and Taste Graph materially improve recommendations, personalization, or decision-making beyond generic LLM guessing.
- **Qloo Taste Graph:** Bridges cultural affinities across 250M+ entities across music, film, television, books, podcasts, dining, fashion, brands, and travel.

## 2. Key Hackathon Requirements

1. **Substantive Qloo Integration:**
   - The application must directly integrate Qloo's API / Taste Graph.
   - Cultural intelligence must be central to the agent's reasoning, not a cosmetic add-on.
2. **Working Demonstration:**
   - A live, testable proof-of-concept / demo endpoint showcasing end-to-end functionality.
3. **Public Repository:**
   - Clean, reproducible open-source repository with documentation, setup instructions, and evaluation methodology.
4. **Transparent Evaluation:**
   - Realistic evaluation including failure analysis and edge cases.
   - Strict avoidance of fabricated metrics or simulated deployment claims.

## 3. Current Project Status

- **Status:** Initial repository setup complete. Application implementation not yet started.
- **Use Case:** Candidate use cases are currently under evaluation. Potential domains include:
  - Cross-domain cultural concierge (film-to-dining / literature-to-travel taste translation).
  - Dynamic content / media recommendation agent with taste clustering.
  - Context-aware marketing persona generator grounded in empirical taste correlation.
- **Dependencies & Credentials:** No API keys or credentials committed. No infrastructure provisioned.
