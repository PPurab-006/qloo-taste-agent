# qloo-taste-agent

> **Qloo Agentic Hackathon** &bull; AI-Powered Cultural Intelligence Agent

---

## 1. Project Overview

**qloo-taste-agent** is an upcoming AI-powered application designed to leverage **Qloo's cultural intelligence API and Taste Graph** to materially improve recommendations, taste predictions, and automated decisions.

Rather than relying on generic LLM heuristics or ungrounded guesses, the agent integrates Qloo's deep taste graph (spanning 250M+ entities across entertainment, literature, dining, fashion, and lifestyle) to ground decisions in real-world cultural affinity data.
